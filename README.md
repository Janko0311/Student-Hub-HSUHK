🚀 A modern, clutter-free alternative dashboard and student portal for HSUHK. Say goodbye to information overload.


> *"Everything you need. Beautifully in sync."*

An open-source, beautifully crafted alternative student dashboard for **The Hang Seng University of Hong Kong (HSUHK)**. Designed with a modern glassmorphism UI to eliminate information overload and make navigating campus life effortless.

---

## ✨ Features

- **🏠 Home:** A clean, centralized hub providing quick, clutter-free access to core student systems.
- **📚 Exchange & Internship:** Curated global opportunities paired with a stunning visual card layout.
- **⭐ Flagship Program (Honours Academy):** Dedicated overview of HSUHK's elite academy, highlighting 100% free benefits and interactive data counters.
- **🎨 Modern Design:** Built with pure HTML5, modern CSS3 (radial gradients & backdrop filters), and vanilla JavaScript.
